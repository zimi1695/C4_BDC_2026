# 项目完整解读 ---- 2026年中国高校计算机大赛—大数据挑战赛


一、我们在做什么

用一句话概括：
每周从沪深300的300只股票里，用历史数据训练一个模型，让模型预测"下周哪5只股票涨得最多"，然后把这5只股票提交给比赛评分。


二、整个流程是什么

  历史股价数据（2020年至今）
        ↓
① 计算特征（这只股票最近表现如何？）
        ↓
② 生成标签（这只股票下周实际涨了多少？）
        ↓
③ 训练模型（学习"什么样的特征对应什么样的涨幅"）
        ↓
④ 预测（用今天的特征预测下周涨幅排名）
        ↓
⑤ 选出Top5（排名前5的股票提交）


三、什么是特征

特征就是描述一只股票当前状态的数字。

动量类（最近涨了多少）
ret_1d   = 今天相对昨天涨了多少
ret_2d   = 今天相对2天前涨了多少
ret_3d   = 今天相对3天前涨了多少
ret_5d   = 今天相对5天前涨了多少（约1周）
ret_10d  = 今天相对10天前涨了多少（约2周）
ret_20d  = 今天相对20天前涨了多少（约1月）

波动率类（涨跌幅度有多剧烈）
vol_5d   = 最近5天的收益率标准差
vol_10d  = 最近10天的收益率标准差
vol_20d  = 最近20天的收益率标准差
标准差是什么：衡量数据波动幅度的数学工具。vol_5d大 = 最近5天每天涨跌很剧烈；vol_5d小 = 每天涨跌平稳。

均线类（价格在趋势中的位置）
price_ma5_ratio  = 今日收盘价 / 5日均线
price_ma10_ratio = 今日收盘价 / 10日均线
price_ma20_ratio = 今日收盘价 / 20日均线
均线（MA）：过去N天收盘价的平均值。price_ma5_ratio > 1 说明今天价格在5日均线上方，处于短期上升趋势。

量比类（成交量是否异常放大）
vol_ratio_5d  = 今日成交量 / 5日平均成交量
vol_ratio_10d = 今日成交量 / 10日平均成交量
vol_ratio_3d  = 今日成交量 / 3日平均成交量
turnover_ratio_5d = 今日换手率 / 5日平均换手率
amount_ratio_5d   = 今日成交额 / 5日平均成交额
amount_ratio_3d   = 今日成交额 / 3日平均成交额
量比 > 1 说明今天成交量比平时大，可能有重要消息或资金异动。

价格位置类（在区间里处于哪里）
price_position_20d = (今日价 - 近20日最低) / (近20日最高 - 近20日最低)
price_position_5d  = 同上，但只看5日区间
price_high5_ratio  = 今日价 / 近5日最高价
price_low5_ratio   = 今日价 / 近5日最低价
结果在0~1之间。接近1说明今天价格在近期高位，接近0说明在近期低位。

技术指标类（金融领域常用的分析工具）
rsi_14     = RSI相对强弱指数（14日）
macd       = MACD指标主线
macd_signal = MACD信号线
macd_hist  = MACD柱状图（主线-信号线）
RSI（相对强弱指数）：衡量一段时间内上涨力量vs下跌力量的比值，范围0~100。RSI > 70 通常认为超买（涨多了可能要跌），RSI < 30 认为超卖（跌多了可能要涨）。
MACD：两条不同周期指数移动平均线的差值，用来判断趋势方向和动量强弱。MACD > 0 说明短期均线在长期均线上方，处于上升趋势。

新增特征（本项目加入的）
near_52w_high = 今日价 / 近252日最高价（接近年内高点的程度）
upper_shadow  = 上影线长度 / 当日振幅（多头被压制的程度）


四、什么是标签（Label）

标签就是我们希望模型预测的答案。
label[T] = open[T+5] / open[T+1] - 1

翻译成人话：
在 T 日（周五）收盘后，我们用当天的特征做预测
实际交易发生在 T+1 日（下周一）开盘买入
T+5 日（下周五）开盘卖出

label = 这5天的实际收益率
训练时：模型看2023年至今每一天每只股票的特征，以及那天之后5个交易日的实际涨幅，学习"什么特征对应什么涨幅"。
预测时：模型看最新一天的特征，输出每只股票"预测的下周涨幅"，取前5名提交。


五、什么是 LightGBM（LGBM）
先理解决策树
假设你要预测一只股票下周涨还是跌，可以这样做：

RSI > 70？
├── 是 → 最近5天涨幅 > 10%？
│         ├── 是 → 预测：跌（超买且涨太多）
│         └── 否 → 预测：继续涨（强势）
└── 否 → 成交量放大了？
          ├── 是 → 预测：涨（量价齐升）
          └── 否 → 预测：横盘

这就是一棵决策树：通过一系列 if-else 判断，最终给出预测。
GBDT：很多棵树叠加
单棵决策树太简单，容易出错。GBDT（梯度提升决策树） 的思路是：

第1棵树：预测涨5%，实际涨8%，误差=3%
第2棵树：专门预测第1棵树的误差，输出2.5%
第3棵树：预测剩余误差0.5%
...
最终预测 = 5% + 2.5% + 0.5% + ... = 接近8%
每棵新树都在纠正前面所有树的错误，最终几百棵树的预测叠加在一起，精度大幅提升。

LightGBM 是什么
LightGBM 是微软开发的 GBDT 的高效实现，比传统 GBDT 快10倍以上，是目前量化金融、数据竞赛里最常用的模型之一。

我的模型参数：
n_estimators  = 500   # 总共500棵树
learning_rate = 0.05  # 每棵树的贡献权重（越小越保守）
num_leaves    = 64    # 每棵树最多64个叶节点（分支数量）


六、什么是截面 Z-Score 标准化

问题：600519（茅台）股价2000元，000001（平安银行）股价15元，直接放在一起比较没意义。
解决方案：每天对所有300只股票的同一特征做标准化：
标准化后的值 = (原始值 - 当天所有股票的均值) / 当天所有股票的标准差

效果：
标准化后，每天每个特征的均值=0，标准差=1
值=+2 表示这只股票在今天所有股票里排名靠前（高于均值2个标准差）
值=-2 表示排名靠后
这样模型看到的是相对排名，而不是绝对数值，消除了股价高低的干扰。


七、什么是滚动训练（Walk-forward Validation）

不能用未来数据训练模型！
如果你用2026年的数据训练，再用2025年的数据测试，模型"提前知道了未来"，结果毫无意义。

正确做法是滚动训练：
第1周测试（3月9日～13日）：
  训练数据：2024-09-05 ～ 2026-02-27（最近504个交易日）
  预测：2026-03-06这天的特征 → 预测下周涨幅

第2周测试（3月16日～20日）：
  训练数据：2024-09-12 ～ 2026-03-06
  预测：2026-03-13这天的特征 → 预测下周涨幅

...以此类推
每周向前滚动一步，训练集也跟着滚动，严格保证预测时看不到未来数据。


八、什么是 IC（信息系数）
IC = 特征值与未来收益率之间的相关性，用 Spearman 相关系数衡量。

某天300只股票：
  rsi_14 排名  vs  下周实际收益率排名
  
  如果 rsi_14 高的股票下周确实涨得多 → IC为正（特征有效）
  如果 rsi_14 高的股票下周反而跌     → IC为负（反向有效）
  如果完全随机                      → IC≈0（特征无效）
但我们发现：
IC≈0 不代表特征对 LightGBM 没用，因为 LightGBM 能捕捉非线性关系，而 IC 只衡量线性相关。
这就是为什么删掉 IC≈0 的特征后，结果反而更差。

十、为什么模型表现不稳定

金融预测是世界上最难的预测问题之一，原因：
信噪比极低：影响股价的因素成千上万，历史数据里真正有用的规律很少
市场会学习：一旦某个规律被发现，所有人都用它，规律就失效了
黑天鹅事件：关税、疫情、政策等突发事件无法从历史数据预测
5只股票太少：单周5只股票的随机性很大，一只股票的涨跌就能影响整体收益率±2%

这也是为什么我们的回测收益起伏很大——这不是模型问题，是金融预测的固有属性。
